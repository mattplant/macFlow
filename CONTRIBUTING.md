# Contributing to macFlow

Thanks for your interest in macFlow.

**Development happens on GitLab:** <https://gitlab.com/beginnermind/macFlow>

The GitHub repository is a read-only mirror, kept in sync automatically. Anything
pushed or opened there will be overwritten or go unread, so please:

- **File issues** at <https://gitlab.com/beginnermind/macFlow/-/issues>
- **Open merge requests** at <https://gitlab.com/beginnermind/macFlow/-/merge_requests>

Pull requests opened against the GitHub mirror cannot be merged. If you have already
opened one, please re-open it as a merge request on GitLab — the contribution is
welcome, just on the other side.
